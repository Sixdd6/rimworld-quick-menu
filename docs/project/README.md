# docs/project

The agent team writes the project's working artifacts here: `STATUS.md`, `idea.md`, `spec.md`, `architecture.md`, `decisions/`, `design.md`, `assets.md`, `design/` (mockups and review screenshots), `game-design.md`, `data-ml.md`, `operations.md`, `performance.md`, `environment.md`, `plan.md`, and `releases/`.

It is empty in the template. Run `/kickoff "<your idea>"` to start. See the root `CLAUDE.md` for the workflow.
